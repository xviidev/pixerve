# Pixerve logo

![Pixerve](pixerve-logo.svg)

Use [pixerve-logo.svg](pixerve-logo.svg) for scalable displays. A PNG copy is
available as [pixerve-logo.png](pixerve-logo.png).

Application artwork lives in `assets/`; `static/` holds replaceable public files.
Error responses use `assets/error.svg` and `assets/logo.svg`.

| Asset | File |
|---|---|
| Default Open Graph card | [default-og.png](../assets/default-og.png) |
| README hero cover | [readme-cover.png](../assets/readme-cover.png) |
| Icon master | [pixerve-icon.png](../assets/pixerve-icon.png) |

See [asset usage](../apps/docs/src/content/docs/guides/assets.md).
